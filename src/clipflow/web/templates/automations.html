1. Control de Calidad Estricto (MediaQA)

Valida cada render MP4 generado por AutoClip antes de permitir su publicación

Regla Activa
1. Disparador
Render finalizado
AutoClip completa un corte vertical 9:16
2. Condición
FFprobe 9:16 + H.264/AAC
Archivo íntegro, audio válido y duración permitida
3. Acción
Indexar en Biblioteca
Genera miniatura FFmpeg local sin duplicar el video
4. Resultado
Listo para Publisher

2. Programación Inteligente por Zona Horaria

Normaliza horarios de America/Santo_Domingo (UTC-4) a UTC persistente en SQLite

Worker Supervisado
1. Disparador
Borrador aprobado
Usuario selecciona horario en Publisher o Calendar
2. Condición
Clave de Idempotencia única
Previene duplicados ante reinicios o doble clic
3. Acción
Subida resumible por bloques
Worker despacha al vencer scheduled_at_utc
4. Resultado
ID y URL confirmados
Se registra video_id real y se verifica por API

3. Pausa Preventiva ante Fallos de Autorización

Evita quemar cuota o lanzar reintentos fallidos si expira un token OAuth

Protección Activa
1. Disparador
Error HTTP 401 / Token Expirado
Detectado durante la subida o verificación
2. Condición
Renovación automática falla
refresh_token revocado o permisos insuficientes
3. Acción
Marcar conexión EXPIRED
Pausa trabajos pendientes de esa plataforma
4. Resultado
Estado REQUIRES_ACTION
Alerta clara en Overview y Queue para re-autorizar
